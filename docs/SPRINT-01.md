# Sprint 01 — هسته اولیه

## هدف
ساخت یک هسته قابل اجرا و قابل توسعه برای نسخه دسکتاپ Windows 11.

## فناوری‌های انتخاب‌شده
- Python 3.12
- PySide6 برای رابط دسکتاپ
- SQLAlchemy برای لایه دسترسی داده
- Pydantic Settings برای تنظیمات
- pytest برای آزمون

## تصمیم معماری
در نسخه دسکتاپ اولیه، SQLite به‌صورت پیش‌فرض استفاده می‌شود تا نصب ساده باشد. لایه پایگاه داده با SQLAlchemy طراحی شده و بعداً می‌تواند به PostgreSQL منتقل شود بدون اینکه منطق دامنه به پایگاه داده وابسته شود.

## ماژول‌های آینده
- مدیریت اسناد و قوانین
- PDF text extraction
- OCR
- Legal Knowledge Graph
- Rule Engine
- RAG
- AI Provider abstraction
- تحلیل قرارداد
- گزارش و استناد
- Audit Trail
- Plugin SDK
- Backup/Restore
- Installer

## نکته حقوقی
نتایج AI باید قابل استناد، قابل بازبینی و همراه با منبع باشند. برنامه نباید بدون نمایش منبع و سطح اطمینان، نتیجه حقوقی قطعی تلقی‌شده ارائه کند.
