# ParsLaw AI Enterprise

سامانه هوشمند مدیریت دانش حقوقی و تحلیل قراردادها.

## هدف نسخه 0.1
این نسخه فقط زیرساخت پروژه را فراهم می‌کند:
- معماری ماژولار
- تنظیمات
- ثبت رخدادها
- پایگاه داده با SQLAlchemy
- رابط کاربری اولیه PySide6
- آماده‌سازی برای PDF، OCR، RAG، Rule Engine و AI

> این نرم‌افزار ابزار کمکی تحلیل حقوقی است و جایگزین نظر و بررسی حقوقی متخصص نیست.

## اجرای توسعه
1. Python 3.12 را نصب کنید.
2. محیط مجازی بسازید.
3. وابستگی‌ها را نصب کنید.
4. برنامه را اجرا کنید.
